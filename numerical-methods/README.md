# Numerical methods

Second-year coursework, variant 15. The reports contain methods, implementation excerpts and results; the accompanying Python scripts contain the original calculations.

| 4 | Polynomial interpolation | [PDF](lab-04-interpolation/report.pdf) | [Python](lab-04-interpolation/solution.py) |
